## Environment caveats (READ FIRST next session)

- **Docker is NOT available in the cloud container.** Integration tests (`*IT`, Testcontainers: Postgres, Keycloak, simulators) **only run in GitHub Actions CI**, never locally. Local validation is limited to:
  - `./mvnw -o test-compile` (offline; dep cache is warm).
  - `./mvnw test` (Surefire unit tests; the **first** run must be online — `-o` fails until the `antrun` plugin is cached).
  - Full `./mvnw verify` locally = fails on the ~5 container-dependent IT classes; that's expected.
- **GitHub write:** the MCP github tools (as the user's OAuth) work for branch pushes, PR create/merge, reruns. `git push` of **branch commits** works. **BUT** this token **refuses tag pushes and ref deletions** ("remote end hung up"). Anything needing those must be done by the user.
- **CI = `.github/workflows/ci.yml`** → single `build` job running `./mvnw verify` (Surefire + Failsafe ITs with Docker). Check status via `mcp__github__pull_request_read method=get_check_runs`.

The main session then **gates on CI** and merges on green (`merge_pull_request` with `expected_head_sha`). Subagents can't run ITs (no Docker), so **CI is the real gate** — merge nothing red.
