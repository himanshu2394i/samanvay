Samanvay

How Samanvay addresses the problem

Federated interoperability — not a new portal, not a data lake, not an aggregator. Certificates stay at the issuer.

Departments stay owners

Aaple Sarkar, Mahabhulekh, Fire, MPCB, MahaDBT keep their systems. Samanvay sits between them.

Nothing stored except proof

Links, consent, pointers, workflow, tracking, hash-chained audit. Payloads are fetched live, then discarded.

Three callers, one core

Scholarship, licence/NOC, and farmer subsidy are ready skins on published catalog journeys — no extra Java for farmer.

Connect department accountsMap IDs. Probabilistic matches never auto-merge.

DigiLocker may carry issued copies. It is not login and not Samanvay’s consent store.

02

03

Control plane decides

Access authorityIdentity + consent + registry pointer, as one decision
Any no → denyReason written on the audit chain
All yes → signed grant60-second TTL, single-use nonce. No fetch without it.

Control plane decides. Data plane cannot call a department “just this once”.
