## Environment caveats (READ FIRST)

- **No Docker in the cloud container.** Integration tests (`*IT`, Testcontainers: Postgres,
  Keycloak, SFTP, SOAP/bank sims) run **only in GitHub Actions CI**. Locally you get
  `./mvnw -o test-compile` and `./mvnw test` (Surefire; first run must be online to fetch the
  `antrun` plugin). Subagents validated some ITs against a temporary local Postgres and reverted.
- **GitHub token quirks:** branch-commit pushes + PR create/merge + reruns work. **Tag pushes
  and ref deletions are refused** ("remote end hung up") — those are yours to do.
- **MCP (github) disconnects/reconnects intermittently** — reload tools via ToolSearch
  (`select:mcp__github__pull_request_read,mcp__github__merge_pull_request`) after a reconnect.
- **CI = `.github/workflows/ci.yml`** → `build` job runs `./mvnw verify`. The SPA has its own
  `frontend` job (npm build/lint/test, no Docker). A PR touching both Java + `frontend/` runs
  both checks; both must be green.
- **Maven Central occasionally 502s** on a cold runner (infra flake) → `rerun_failed_jobs` once.
- **Migrations:** latest on `main` is **V197**. In-flight PRs may claim V198/V199 — watch for
  collisions and renumber the loser at merge.
- **Commit trailer** on every commit:
  ```
  Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01XeaiDJMbDsE7REhn37rFAf
  ```
  PR bodies end with the `_Generated by [Claude Code](https://claude.ai/code)_` footer.
- **Workflow that worked:** a sonnet subagent prepares each change in its own git worktree off
  latest `main`, validates locally, pushes a branch, opens a PR (does NOT merge). Main session
  gates on CI (`get_check_runs`) and merges on green (`merge_pull_request` + `expectedHeadSha`).
  Subagents can't run ITs (no Docker) — **CI is the real gate; merge nothing red.**
